# Bundled typefaces

All fonts are shipped with the app; none are fetched at runtime. They were
retrieved from the Google Fonts repository at commit
`296bb4790d3f9bd95547c733708a3666ed35d844` and remain under their respective
SIL Open Font Licenses, included beside the binaries.

| Family | Repository path | Use |
|---|---|---|
| Inter | `ofl/inter/Inter[opsz,wght].ttf` | Interface and controls |
| Newsreader | `ofl/newsreader/Newsreader[opsz,wght].ttf` | Long-form assistant reading text |
| Source Code Pro | `ofl/sourcecodepro/SourceCodePro[wght].ttf` | Code blocks and inline code |

The Google Fonts repository is <https://github.com/google/fonts>.
